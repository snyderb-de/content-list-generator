Getting Started

Download the right build

Pick based on your platform:

  • macOS — download content-list-generator-gui-darwin-universal.zip. Unzip, drag the .app to Applications. First launch may trigger Gatekeeper — right-click → Open.
  • Windows (recommended) — download content-list-generator-windows-portable.zip. Unzip anywhere. Run Start Content List Generator.cmd. No installer or admin rights required.
  • Windows (native GUI) — content-list-generator-gui-windows-amd64.exe. Currently under investigation — silent exit on some Win11 hosts. Use portable until fixed.
  • Linux — download content-list-generator-linux-amd64. Terminal UI. chmod +x then run.

All releases live at github.com/snyderb-de/content-list-generator/releases/latest.

Core Workflows

1. Generate a content list

Scan a folder recursively and write a CSV inventory of every file found.

  1. Pick a source folder.
  2. Pick an output folder (defaults to source).
  3. Adjust settings (hash algorithm, exclusions, XLSX option).
  4. Click Start scan.

Output: <folder-name>-content-list-<timestamp>.csv. Scans over 300,000 rows split into chunks: -001.csv, -002.csv, …

2. Copy email files

Find every email file under a source folder and copy them into a destination, preserving the folder structure. Generates a manifest report.

Supported extensions: .eml, .msg, .pst, .ost, .mbox.

3. Clone compare (Phase 7)

Compare two drive scans to verify a successful clone. Produces a verdict (Exact Match, Metadata Clone, Mismatch) and a diff report.

Settings Reference

Hash algorithms

  • Off — fastest, no hashing
  • SHA-1 — fast, widely used legacy default
  • SHA-256 — slower, cryptographically stronger
  • BLAKE3 — fastest secure hash; requires the blake3 Python package for the Python runtime

Exclusions

  • Hidden files — files starting with a dot or with the hidden attribute set
  • System files — .DS_Store, Thumbs.db, desktop.ini, etc.
  • Extension filter — comma-separated list, e.g. tmp,log,bak

Output options

  • Create XLSX — generate an Excel copy alongside the CSV
  • Preserve leading zeros — keep zero-padded filenames intact in the XLSX
  • Delete CSV after XLSX — clean up the intermediate CSV once the XLSX exists

Troubleshooting

macOS — "could not verify free of malware"

The binary is unsigned. Gatekeeper blocks it by default. Three ways to bypass:

  • Right-click the .app → Open → "Open" button
  • System Settings → Privacy & Security → scroll to "was blocked" → "Open Anyway"
  • Terminal: xattr -d com.apple.quarantine /path/to/Content\ List\ Generator.app

Windows — SmartScreen warning

The .exe is not yet code-signed. Click "More info" → "Run anyway". Once signed (planned), this will go away.

Windows — .exe doesn't launch (silent exit)

Known issue on some Win11 hosts. Use the portable .zip in the meantime. Investigation tracked in docs/debug/windows-launch-failure.md.

FAQ

What's the difference between the .exe and the portable .zip on Windows?

The .exe is a native Wails app using the Edge WebView2 runtime. The portable .zip is a Python tkinter app bundled with its own Python runtime via PyInstaller. Different code paths, same scanning behavior.

Why is there a TUI (terminal) version?

The Linux content-list-generator-linux-amd64 is the Bubble Tea TUI — full-screen terminal UI. Useful for headless servers or SSH sessions where running a GUI isn't practical.

Do my scan settings persist between sessions?

Yes. Settings are stored in:

  • macOS: ~/Library/Application Support/content-list-generator/
  • Windows: %APPDATA%\content-list-generator\
  • Linux: ~/.config/content-list-generator/
  • Windows portable: in the data\ folder next to the launcher
